# Launch Checklist

- Confirm final content, metrics, and legal copy are approved.
- Confirm portfolio image rights are cleared.
- Confirm licensed webfont files are available if the logo-only fallback should be replaced.
- Confirm the public Google Form URL remains live.
- Run `npm run check`.
- Run `npm run build`.
- Run `npm run test`.
- Run `npm run test:smoke`.
- Verify sitemap, robots, canonicals, and schema output.
- Verify mobile layout and reduced-motion fallback.
- Validate Netlify preview with stakeholder sign-off.
- Attach `cakemarketingllc.com` to the live Netlify project.
- Execute DNS cutover and re-run smoke checks on production.
