# Launch Checklist

- Confirm final content, metrics, and legal copy are approved.
- Confirm font licenses and portfolio image rights are cleared.
- Confirm public Google Form URL is live.
- Run `npm run check`.
- Run `npm run build`.
- Run `npm run test`.
- Run `npm run test:smoke`.
- Verify sitemap, robots, canonicals, and schema output.
- Verify mobile layout and reduced-motion fallback.
- Validate Netlify preview with stakeholder sign-off.
- Execute DNS cutover and re-run smoke checks on production.
